# FitAI Studio

Standalone Vite + React app (Task 17). Component: `src/components/FitAIStudio/`.

    npm install
    npm run dev

Open the URL shown in the terminal (usually http://localhost:5173).

Build for production: `npm run build` (output in `dist/`).

> `public/models/mannequin.glb` is ~65 MB. GitHub warns above 50 MB (limit 100 MB), so consider Git LFS: `git lfs track "*.glb"`.
